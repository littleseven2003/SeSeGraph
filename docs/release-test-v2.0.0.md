# SeSeGraph v2.0.0 五分钟实测流程

适用版本：`v2.0.0`（升级提交以运维通知的 SHA 为准）
测试目标：确认登录、上传、任务进度、图集预览与设置四组十项在新版本上工作正常。

> 说明：本版没有「分析 / 三维回放」入口，对应的观感验证由图集详情的图片预览与任务页四阶段进度覆盖。

## 准备

- 访问地址：`https://sesegraph.7772003.xyz`（运维通知的实际地址为准）
- 账号：沿用现有生产管理员账号与密码，无需重新初始化
- 素材：准备 2–3 张普通照片（单张小于 5 MB）

## 步骤（约 5 分钟）

### 1. 登录（约 20 秒）

1. 打开地址，应直接进入登录页而不是「初始化管理员」页。
2. 用现有账号登录，能进入首页图集列表。

预期：登录成功，右上角显示账号；刷新后仍保持登录。

### 2. 上传一个新图集（约 2 分钟）

1. 进入「工作台」，新建图集，选择准备好的 2–3 张照片。
2. 观察进度面板的四段：**压缩 → 上传 → 同步 → 发布**。
3. 上传过程中点一次「暂停」，确认在途图片结束后停在暂停状态；再点「继续」恢复。
4. 等待队列清空。

预期：四段依次推进，计数与实际张数一致；暂停/继续生效且不会重复上传；结束后任务进入「已完成」。

### 3. 图集与图片预览（约 1 分钟）

1. 从首页点开刚才的图集，进入详情页。
2. 点任意缩略图，应打开大图预览；按 Esc 或点遮罩关闭。
3. 点眼睛图标「揭开」可切换防社死遮罩；点「复制单图链接」能复制到链接。
4. 点另一张图的「设为封面」，刷新后封面标记落到该图。
5. 若已配置发布，点「复制分享文案」应得到带标题与链接的文案。

预期：预览、遮罩、复制、换封面、分享文案均正常，页面无明显错位或横向滚动。

### 4. 任务页（约 30 秒）

1. 打开「任务」页，找到刚才的任务。
2. 展开任务，确认四阶段、操作按钮与失败明细都在展开区内；折叠后只保留一行摘要。
3. 已完成/未开始的阶段右侧不再出现多余的「待开始」字样。

### 5. 设置页四组十项（约 1 分钟）

打开「设置」，左侧四个分组应完整平铺、顺序为：

1. **连接与发布**：Telegram 图床、Telegraph 发布、网络代理、连通性自检
2. **上传配置**：元信息解析、上传默认
3. **运维与安全**：流量看护、备份与缓存、账号安全
4. **外观配置**：颜色模式

逐项检查：

- 下滑页面时左侧（手机为顶部横向药丸）高亮跟着切换；点菜单平滑定位。
- 在某一组里改一个值但不保存，再去另一组点「保存」，确认只提交该卡片、前一组草稿仍在。
- 点「连通性自检」能读到当前配置的检测结果。
- 「备份与缓存」能显示已占用、条目数与当前上限，能刷新占用、清空缓存。
- 「颜色模式」切换浅色/深色立即生效。
- 浏览器后退能回到上一个设置分组，而不是直接离开设置页。
